# Egyptian League Management System

A simple C++ console application for managing football teams and players in the Egyptian League.  
This program allows users to add, remove, search, update, and display information about teams and players using linked lists.

---

## Project Overview

This project demonstrates Object-Oriented Programming (OOP) and data structure concepts (specifically linked lists) in C++.  
It provides basic functionality for maintaining data about football teams and their players in a text-based interface.

---

## Features

### Team Management
- Add a new team (name, president, and ID)
- Display details of a specific team by ID
- Search for a team by ID

### Player Management
- Add a new player (name, team, position, ID, age, salary)
- Remove a player by name
- Display player details
- Search for a player by name
- Update a player's team information

---

## Classes Overview

### `teamNode` and `teamList`
- `teamNode`: Represents a team node containing team name, president, and ID.
- `teamList`: Manages the linked list of team nodes and provides functions to add, display, and search teams.

### `player_Node` and `playerList`
- `player_Node`: Represents an individual player with details like name, team, position, ID, age, and salary.
- `playerList`: Manages the linked list of players and provides functions to add, remove, search, display, and update players.
